# Contributing

## Scope

This repository is a multi-language learning playground. Keep changes simple, runnable, and educational.

## Conventions

1. Use clear, correctly spelled file and class names.
2. Keep one primary concept per file when possible.
3. Prefer small standalone examples with obvious input/output behavior.
4. Avoid committing generated artifacts (`.exe`, `.class`, object files, etc.).

## Language expectations

1. Java: `public` class name must match file name.
2. Go: run `gofmt` on changed files.
3. TypeScript/JavaScript: keep browser and Node examples explicit in docs.
4. Fortran/C++: keep compile commands documented in `README.md`.

## Pull request checklist

1. Updated or added docs for any new example.
2. Verified changed examples compile/run locally.
3. Confirmed no generated binaries are newly tracked.
4. Naming and folder layout remain consistent.
